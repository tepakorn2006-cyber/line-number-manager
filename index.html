จัดการเบอร์ LINE

จดผลยืนยันเบอร์ที่คุณเห็นในแอป LINE เอง และนัดวันตรวจซ้ำ

เว็บนี้ไม่ได้ตรวจสถานะเบอร์กับ LINE — ผลทุกรายการมาจากที่คุณกรอกเอง นำเข้าจาก CSV หรือข้อความในภาพที่คุณยืนยัน เพราะ LINE ไม่มีช่องทางที่ได้รับอนุญาตให้ตรวจ ดูเหตุผลและหลักฐาน
ข้อมูลจะหายเมื่อปิดหน้า — ส่งออก CSV ไว้ ไปหน้าส่งออก

ส่งออก CSV

เปิดได้ด้วย Excel หรือ Google Sheets — เบอร์เขียนเป็น ="0812345678" เพื่อให้คงเลข 0 ด้านหน้า มีคอลัมน์ “ที่มา” และ “ตรวจอัตโนมัติ” และนำกลับเข้ามาที่แท็บ “เพิ่มเบอร์” ได้ครบทุกช่อง

ทำไมเว็บนี้ตรวจสถานะเบอร์ให้อัตโนมัติไม่ได้

สรุปผลการวิเคราะห์ 5 ข้อ พร้อมหลักฐานจาก LINE เอง:

  1. LINE ไม่มี API หรือช่องทางที่ได้รับอนุญาตสำหรับตรวจสถานะการยืนยันเบอร์ หรือจำนวนวันที่ต้องรอ และตรวจหลายเบอร์ไม่ได้ — Messaging API มีไว้รับส่งข้อความของบัญชีทางการ ส่วน LINE notification messages (PNP) เป็น API สำหรับส่งข้อความ ไม่ใช่ API ตรวจสอบ ต้องเป็นนิติบุคคลที่ได้รับอนุมัติ ห้ามใช้เชิงพาณิชย์ และส่งได้ครั้งละ 1 เบอร์
    developers.line.biz — Messaging API reference
  2. ข้อความ “Please wait XX day(s)” แสดงเฉพาะในแอป LINE และ LINE ระบุว่า “these restrictions cannot be lifted”
    help.line.me — contentId 20000104
  3. LINE ไม่เปิดเผยว่าการจำกัดจะนานเท่าใด — “cannot provide details such as how long the restrictions will last” จึงไม่มีจำนวนวันตั้งต้นที่ถูกต้อง เว็บนี้ไม่เดาให้
    help.line.me — contentId 20000372
  4. อย่า “ทดสอบ” เบอร์ด้วยการลองสมัคร — การสมัครด้วยเบอร์ที่มีบัญชี LINE อยู่แล้ว ทำให้บัญชีเดิมถูกลบ
    help.line.me — contentId 20001192
  5. ข้อกำหนดการใช้งาน LINE ข้อ 15 ห้ามใช้ BOT หรือวิธีการทางเทคนิค (technical means), ห้าม reverse engineering และห้ามเก็บข้อมูลของบุคคลที่สามโดยมิชอบ — การเขียนโปรแกรมไปตรวจเบอร์แทนผู้ใช้จึงขัดข้อกำหนด
    terms.line.me — LINE Terms and Conditions of Use

เว็บนี้จึงทำเท่าที่ทำได้อย่างซื่อตรง

  • ไม่เรียกบริการภายนอกเพื่อตรวจเบอร์ และไม่สร้างผลตรวจหรือจำนวนวันรอขึ้นเอง ไม่มีค่าตั้งต้นจำนวนวัน
  • จำนวนวันรอมาจากที่คุณกรอก หรือจากข้อความในภาพที่คุณอัปโหลดแล้วยืนยันเอง
  • คอลัมน์ “ตรวจอัตโนมัติ” ทุกแถวแสดง “ยังไม่สามารถตรวจสอบอัตโนมัติได้ — ยังไม่พบช่องทางที่ได้รับอนุญาตจาก LINE” และทุกรายการบอก “ที่มา” ของผลล่าสุด
  • ข้อมูลเก็บในเบราว์เซอร์นี้เท่านั้น (localStorage) ไม่เก็บรูปภาพ ไม่มีช่องรหัสผ่านหรือ OTP

ล้างข้อมูลทั้งหมด
