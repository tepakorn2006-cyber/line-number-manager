# จัดการเบอร์ LINE (LINE Number Manager)

เว็บหน้าเดียวสำหรับ **จดผลการยืนยันเบอร์ที่คุณเห็นในแอป LINE เอง** และนัดวันตรวจซ้ำ ไม่ต้องติดตั้งอะไร ไม่มีเซิร์ฟเวอร์ และข้อมูลอยู่ในเบราว์เซอร์ของคุณเท่านั้น

> **เว็บนี้ไม่ได้ตรวจสถานะเบอร์กับ LINE** ผลทุกรายการมาจากที่คุณกรอกเอง นำเข้าจาก CSV หรือข้อความในภาพที่คุณยืนยัน (ดูหัวข้อ “ข้อจำกัด”)

## วิธีเปิดใช้
1. ดับเบิลคลิก `index.html` เพื่อเปิดใน Chrome, Edge, Firefox หรือ Safari รุ่นปัจจุบัน
2. ถ้าเบราว์เซอร์บล็อก OCR หรือ localStorage ตอนเปิดแบบ `file://` ให้เปิดผ่านเซิร์ฟเวอร์ในเครื่องแทน เช่น
   ```
   npx serve .
   # หรือ
   python -m http.server 8000
   ```
   แล้วเข้า `http://localhost:8000`
3. ถ้าเบราว์เซอร์บันทึกข้อมูลไม่ได้ (เช่น โหมดส่วนตัวบางแบบ) หน้าเว็บจะขึ้นแถบเตือน “ข้อมูลจะหายเมื่อปิดหน้า — ส่งออก CSV ไว้”

รันเทสต์ของส่วนประมวลผล (ไม่ต้องติดตั้งแพ็กเกจใด):
```
node tests/test-core.js
```

## ฟังก์ชัน (5 แท็บ)
1. **รายการเบอร์**
   - ตัวเลขสรุป (ทั้งหมด / ต้องรอ / ถึงกำหนด / ใกล้ถึง) กดแล้วกรองรายการตามนั้นได้
   - กล่อง “ถึงกำหนดตรวจซ้ำ / ใกล้ถึงกำหนด”
   - ค้นหา กรองตามสถานะ ที่มา และกำหนด เรียงลำดับได้ และตั้งได้ว่า “ใกล้ถึง” หมายถึงภายในกี่วัน
   - เป็นตารางบนจอใหญ่ และเป็นการ์ดบนจอเล็กกว่า 640px
   - เลือกหลายรายการเพื่อลบหรือเปลี่ยนสถานะ และแก้ไขหรือลบทีละแถวได้ ถ้าแก้เบอร์ของแถวที่มีผลตรวจแล้ว ระบบจะถามว่าจะเก็บผลเดิม (แก้เลขพิมพ์ผิด) หรือล้างผลตรวจ
   - ปุ่ม “บันทึกผลตรวจ” มีฟอร์ม: สถานะ, ข้อความตอบกลับ, จำนวนวันรอ, วันที่เห็นข้อความ, วันนัดตรวจซ้ำ (คำนวณให้และแก้เองได้), ข้อผิดพลาด
   - ทุกแถว (รวมกล่องถึงกำหนดและพรีวิว CSV) มีป้ายที่มา (“ผู้ใช้กรอก” / “อ่านจากภาพ (ผู้ใช้ยืนยัน)” / “นำเข้า CSV”) และคอลัมน์ “ตรวจอัตโนมัติ” ที่แสดงค่าคงที่ “ไม่สามารถตรวจสอบได้ — LINE ไม่มีช่องทางที่ได้รับอนุญาต”
2. **เพิ่มเบอร์**
   - วางได้หลายเบอร์ รองรับขีด เว้นวรรค +66 และเลขไทย
   - พรีวิวก่อนเพิ่ม แยกเป็น ใหม่ / ซ้ำ / ไม่ถูกต้อง (บอกเหตุผล) / เติม 0
   - นำเข้า CSV ได้ อ่านไฟล์ได้ทั้ง UTF-8 และ TIS-620 (Excel ภาษาไทย) และเลือกได้ว่าจะข้ามหรือเขียนทับเบอร์ที่มีอยู่แล้ว
3. **อ่านจากภาพ (OCR)**
   - เพิ่มภาพหน้าจอได้หลายภาพ โดยอัปโหลด ลากวาง หรือวางจากคลิปบอร์ด
   - ใช้ Tesseract.js 5.1.1 (ภาษา `tha+eng`) ซึ่งโหลดครั้งแรกตอนเริ่มใช้ OCR และแสดงความคืบหน้าระหว่างโหลด
   - แสดงภาพคู่กับข้อความที่อ่านได้ (แก้ไขข้อความได้) พร้อมความเชื่อมั่นเฉลี่ย ถ้าต่ำกว่า 70% หรือมีตัวเลขที่ความเชื่อมั่นต่ำ จะเตือน “อ่านไม่ชัด โปรดตรวจ”
   - ตารางเบอร์ที่พบแก้ไขได้ เลือกได้ และเพิ่มเบอร์เองได้ จำนวนวันรอที่พบแก้ได้และเว้นว่างได้ ถ้าพบหลายค่าที่ไม่ตรงกัน จะไม่เลือกให้ แต่ให้คุณเลือกเอง
   - คุณต้องเลือกสถานะเองก่อนบันทึก และผลที่บันทึกจะมีที่มาเป็น `ocr`
   - ระบบไม่เก็บภาพไว้
4. **ส่งออก**
   - ส่งออกเป็น CSV ได้ 4 แบบ: ทั้งหมด / ตามตัวกรองปัจจุบัน / เฉพาะที่ต้องตรวจซ้ำ (เลยกำหนด + วันนี้ + ใกล้ถึง) / เฉพาะสถานะต้องรอ
   - ชื่อไฟล์มีวันที่ เช่น `line-numbers-all-2026-10-15.csv`
   - เบอร์ถูกเขียนเป็น `="0812345678"` เพื่อให้ Excel คงเลข 0 ด้านหน้า
   - ไฟล์ที่ส่งออกนำกลับเข้ามาได้ครบทุกช่อง (วันนัดตรวจซ้ำที่เว้นว่างไว้จะยังว่าง) ถ้าไฟล์ไม่มีคอลัมน์วันนัดตรวจซ้ำ ระบบคำนวณจากวันที่เห็นข้อความ + จำนวนวันรอ และเมื่อเขียนทับเบอร์เดิมด้วยจำนวนวันรอหรือวันที่เห็นข้อความใหม่ วันนัดจะคำนวณใหม่
5. **ข้อจำกัด** — สรุปผลวิเคราะห์ 5 ข้อพร้อมลิงก์หลักฐาน และปุ่มล้างข้อมูลทั้งหมด (ยืนยันผ่านกล่องโต้ตอบในหน้า)

นอกจากนี้: รองรับโหมดมืดตามการตั้งค่าเครื่อง และเปิดบนมือถือกว้าง 360px ได้โดยไม่มีแถบเลื่อนแนวนอน ข้อความทุกอย่างจากผู้ใช้ OCR และ CSV ถูก escape ก่อนแสดง (กัน XSS) และไฟล์ CSV ที่ส่งออกป้องกันการรันสูตร (formula injection)

## ข้อจำกัด (พร้อมหลักฐาน)
- **LINE ไม่มี API หรือช่องทางที่ได้รับอนุญาตสำหรับตรวจสถานะการยืนยันเบอร์ หรือจำนวนวันที่ต้องรอ และตรวจหลายเบอร์ไม่ได้**
  https://developers.line.biz/en/reference/messaging-api/
  - LINE notification messages (PNP) เป็น API สำหรับส่งข้อความ ไม่ใช่ API ตรวจสอบ ต้องเป็นนิติบุคคลที่ได้รับอนุมัติ ห้ามใช้เชิงพาณิชย์ และส่งได้ครั้งละ 1 เบอร์
- **ข้อความ “Please wait XX day(s)” แสดงเฉพาะในแอป** และ LINE ระบุว่า “these restrictions cannot be lifted”
  https://help.line.me/line/smartphone/?contentId=20000104&lang=en
- **LINE ไม่บอกว่าการจำกัดจะนานเท่าใด** (“cannot provide details such as how long the restrictions will last”) เว็บนี้จึงไม่มีจำนวนวันรอตั้งต้น
  https://help.line.me/line/?contentId=20000372
- **การสมัครด้วยเบอร์ที่มีบัญชีอยู่แล้วทำให้บัญชีเดิมถูกลบ** จึงไม่ควร “ทดสอบ” เบอร์ด้วยการลองสมัคร
  https://help.line.me/line/?contentId=20001192&lang=en
- **ข้อกำหนดการใช้งาน LINE ข้อ 15** ห้ามใช้ BOT หรือวิธีการทางเทคนิค ห้าม reverse engineering และห้ามเก็บข้อมูลบุคคลที่สามโดยมิชอบ
  https://terms.line.me/line_terms?lang=en

ข้อจำกัดทางเทคนิคของเว็บนี้:
- **ข้อมูลอยู่ใน localStorage ของเบราว์เซอร์และเครื่องนี้เท่านั้น** ถ้าล้างข้อมูลเว็บหรือเปลี่ยนเครื่อง ข้อมูลจะหาย ควรส่งออก CSV สำรองไว้เป็นระยะ
- **OCR ต้องใช้อินเทอร์เน็ตครั้งแรก** เพื่อดาวน์โหลด Tesseract.js และข้อมูลภาษาจาก jsDelivr (หลาย MB) ความแม่นยำขึ้นกับความคมชัดของภาพ ผลจึงเป็นเพียงข้อเสนอ และคุณต้องตรวจกับภาพเองก่อนบันทึก
- **บางเบราว์เซอร์อาจไม่ให้ OCR ทำงานเมื่อเปิดแบบ `file://`** ถ้าเจอปัญหานี้ ให้ใช้เซิร์ฟเวอร์ในเครื่องตามหัวข้อ “วิธีเปิดใช้”
- **รับเฉพาะเบอร์ไทย** (มือถือ 10 หลักขึ้นต้น 06/08/09, เบอร์บ้าน 9 หลักขึ้นต้น 02–07, +66) เบอร์ที่ใช้รหัสประเทศอื่นจะถูกปฏิเสธ
- **ระบบไม่เก็บภาพ** และไม่มีช่องรหัสผ่านหรือ OTP ห้ามอัปโหลดภาพที่มีรหัส OTP

## แนวทางพัฒนาต่อ
- ส่งออกหรือนำเข้าเป็นไฟล์ JSON สำรองทั้งชุด (รวมการตั้งค่า)
- เตือนวันนัดตรวจซ้ำผ่าน Notification API หรือไฟล์ปฏิทิน `.ics` (เตือนวันที่ผู้ใช้กำหนด ไม่ใช่การตรวจเบอร์)
- ทำเป็น PWA ใช้แบบออฟไลน์ได้ และแคช Tesseract.js กับข้อมูลภาษาไว้ในเครื่อง
- ปรับภาพก่อน OCR (ครอปบริเวณข้อความ เพิ่มคอนทราสต์) เพื่อเพิ่มความแม่นยำ
- เพิ่มเทสต์ UI อัตโนมัติด้วยเบราว์เซอร์ headless
- ถ้า LINE เปิดช่องทางทางการสำหรับตรวจสถานะในอนาคต ค่อยพิจารณาเชื่อมต่อ หลังตรวจข้อกำหนดแล้วเท่านั้น
